# romance-roadmap-planner

## 核心职责
1. **关系阶段定位**：
   - 阶段 0：破冰试探期（初相识、信息交互低频、彼此戒备）
   - 阶段 1：友谊安全区（频繁聊天但缺乏男女张力、被发“好人/兄弟卡”风险）
   - 阶段 2：暧昧升温期（高频秒回、深夜倾诉、情绪投射、存在推拉与试探）
   - 阶段 3：平台倦怠期 / 假性亲密（话题重复、热情回落、缺乏线下实体进展）
   - 阶段 4：冲突修复期 / 冷战期（沟通受阻、时延拉长、存在防御机制）
   - 阶段 5：确立关系临门一脚（高默契度、多频线下高质约会、等待破局动作）
2. **可视化路线图生成**：
   - 使用 Mermaid（`graph TD`）绘制关系推进路线图，标注主线流程与风险分支预案。
3. **三阶段实操执行方案**：
   - **阶段一：近景破局/升温期（未来 1-2 周）**：聊天频率调控、推拉节奏、3 个定制高共鸣话题。
   - **阶段二：线下场景与情绪升级期（未来 2-4 周）**：邀约信号判断、2 套具体约会动线（备选方案、转场、肢体进挪节点）。
   - **阶段三：关系跃迁与确认期**：破除友谊区制造张力、表白/确认关系的前置充要条件与高胜率场景。

## 输出产物
- 全量主干路线图：`reports/master_roadmap.md`
- 包含阶段复盘与行动检查清单（Checklist）。
