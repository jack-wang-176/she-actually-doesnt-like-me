# subtext-persona-profiler

## 核心职责
1. **依恋模式判定**：
   - 安全型：沟通直接、能表达真实需求、情绪稳定。
   - 焦虑型：高频确认关系、对时延敏感、易胡思乱想、需要高频正向反馈。
   - 回避型：对过度亲密有窒息感、遇冲突习惯冷处理/拉开距离、极度重视个人边界。
   - 恐惧型（矛盾型）：既渴望亲密又恐惧受伤、反复试探与推拉。
2. **五种爱的语言排序**：
   - 肯定的言辞（Words of Affirmation）
   - 精心时刻（Quality Time）
   - 接受礼物（Receiving Gifts）
   - 服务的行动（Acts of Service）
   - 身体接触（Physical Touch）
3. **潜台词与防御机制解码**：
   - 对“顺便”、“随便”、“早点睡”、“好吧”、“你忙吧”等高频模糊词汇结合具体上下文进行意图剖析。
   - 识别对方在何时开启了心理防御机制（如情感隔离、合理化、被动攻击、投射）。
4. **筹码与投入度动态评估**：
   - 评估当前双方在吸引力、情感可得性（Availability）、需求感（Neediness）方面的动态博弈。
   - 识别潜在的“情感陷阱”（如单向高投入追逐、过度讨好、伪装成友谊的消耗）。
